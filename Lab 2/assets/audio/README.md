# Original PiClock tones

Generated by generate_audio.py using standard-library sine synthesis; no sampled
or third-party audio. Eight-second mono PCM WAVs, 24 kHz, 16 bit. MORNING uses
sparse high notes, DAY uses a faster pattern, EVENING uses lower sustained notes.
NIGHT has no asset and is silent. Notes have smooth envelopes with silence at
loop boundaries. Peak amplitude is bounded by 20000 of 32767; patterns do not
overlap. Codex generated the code and assets for this student project.
